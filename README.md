**Savor Bistro – Restaurant Website** is a fully responsive multi-page restaurant website designed to showcase the restaurant’s story, menu, outlets, new launches, and reservation system.
The project focuses on clean UI, structured navigation, and user-friendly design using modern web technologies.

**Features**
1. Home Page – Overview of the restaurant, gallery, and news updates
2. Menu Page – Categorized cuisines with images
3. Reservations Page - Dine-in reservations and Special event reservations
4. What’s New Page – Chef’s new launches, upcoming dishes, top-rated items
5. Outlets Page – Restaurant locations with details
6. History Page – Restaurant legacy across generations
7. Contact Us – Contact details and customer feedback

**Technologies Used**
1. HTML5– Page structure
2. CSS – Styling and layout
3. Bootstrap 5 – Responsive design and components
4. JavaScript – Interactivity and form handling
5. jQuery – Dynamic UI behavior

**Project Objective**
The objective of this project is to:
1. Build a **realistic restaurant website**
2. Practice **front-end development**
3. Apply **responsive design principles**
4. Organize a multi-page web project professionally

Open home.html in any modern browser, or Use VS Code Live Server
